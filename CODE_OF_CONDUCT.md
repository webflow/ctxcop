# Code of Conduct

This project adopts the **Contributor Covenant v2.1** verbatim. The canonical
text is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/
and is incorporated here by reference.

In short: be respectful, assume good faith, and remember that contributors
to a security tool come from many backgrounds and time zones. The covenant
lists the specifics.

## Enforcement contact

Reports of code-of-conduct violations go to `security@webflow.com`. We
reuse the same channel as vulnerability reports — different inbox name
would imply different handling, and we'd rather have one well-monitored
address than two half-monitored ones.

The Webflow Infrastructure Security team triages reports within the same
SLA as security advisories (acknowledgment in 3 business days, initial
assessment in 7). All reports are handled confidentially; reporter
identity is not shared with the subject of the report without explicit
permission.

## Scope

This code applies to all ctxcop project spaces: the GitHub repository
(issues, PRs, discussions, code review comments), any official chat or
forum channels, and any in-person or virtual events where someone is
representing the project. Off-project behavior is in scope when it
materially affects the safety of someone in a project space.

## Enforcement guidelines

We follow the Contributor Covenant's standard enforcement ladder:
correction → warning → temporary ban → permanent ban, applied
proportionally and documented in the report file. Severe violations skip
rungs.
